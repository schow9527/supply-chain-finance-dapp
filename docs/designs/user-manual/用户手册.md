## 一、使用前准备

### 1.1 安装与配置 MetaMask

1. 在浏览器安装 [MetaMask](https://metamask.io/) 扩展（推荐 Chrome / Edge）。
2. 打开 MetaMask → 左上角网络选择器 → 选择 **Sepolia 测试网**。
   - 若列表中没有：设置 → 网络 → 显示测试网，然后启用 Sepolia。
3. 每个角色需要一个独立的钱包地址（共 5 个演示账户）。

### 1.2 领取测试币

| 币种 | 用途 | 领取方式 |
| :--- | :--- | :--- |
| Sepolia ETH | 支付链上交易 Gas | Sepolia 水龙头（如 sepoliafaucet.com、Google Web3 Faucet） |
| mUSD 测试稳定币 | 报价放款、到期付款 | 在 DApp 内点击「领取测试币」（`faucet()`），每次可领取固定金额 |

### 1.3 界面入口

打开部署链接后：

- **未连接钱包**：只能浏览首页，点击「连接 MetaMask」发起连接。
- **未注册地址**：自动进入注册申请页。
- **已授权地址**：自动跳转对应角色的工作台。

## 三、通用操作

### 3.1 连接钱包

点击首页「连接 MetaMask 钱包」→ MetaMask 弹出授权窗口 → 确认。连接后右上角显示地址缩写。

- 切换钱包账户后，页面会根据新地址的链上角色**自动切换**对应工作台。
- 未注册的地址只能看到注册申请页。

### 3.2 识别一次链上交易

所有「上链」按钮（提交发票、确认、报价、付款等）点击后按以下流程执行：

1. **前端校验**：表单合法性（金额 > 0、到期日晚于今天等）。
2. **Gas 预估**：按钮附近显示预估 Gas 费用。
3. **MetaMask 签名**：在弹出窗口中确认交易。
4. **等待确认**：交易广播到 Sepolia，页面显示 pending 状态。
5. **结果提示**：成功显示交易哈希与区块浏览器链接；失败显示合约返回的错误原因。

### 3.3 查看交易历史与事件日志

- **交易历史中心**（全角色）：当前地址的所有链上交易，可按类型筛选，每条附 Sepolia 区块浏览器链接。
- **合约事件日志**（管理员、审计员）：全平台合约事件，支持按事件类型、时间、地址筛选。

## 四、供应商操作指南

### 4.1 注册入驻

1. 连接钱包后，在注册申请页填写**企业名称、联系人**。
2. 选择角色「供应商」，提交申请。
3. 等待管理员审核（可在审核进度条查看状态）。
4. 审核通过后**刷新页面**，自动进入供应商工作台。

### 4.2 上传发票（核心步骤）

1. 侧边栏进入「上传发票」。
2. 填写：发票号、核心企业地址（必须为已注册的核心企业）、金额（mUSD）、到期日（必须晚于今天）。
3. 上传发票 PDF：文件存链下，系统自动计算 **SHA-256 哈希**并填入哈希框（只读）。
4. 核对信息后点击「提交上链」，在 MetaMask 中确认。
5. 系统按「发票号 + 买方 + 卖方 + 金额」组合在链上查重：
   - **已存在** → 交易被合约拒绝，提示「发票已存在」（这是防重复融资的第一道闸）。
   - **通过** → 状态变为「待确认」，等待核心企业确认。

### 4.3 管理应收凭证

进入「我的应收凭证」，每张凭证显示：凭证 ID、核心企业、面值、到期日、状态（正常 / 冻结 / 逾期）。

**拆分转让**：

1. 点击凭证行的「拆分转让」。
2. 填写接收方地址（**仅限已注册的供应商**）和转让份额（≤ 持有余额）。
3. 确认上链。已冻结或已到期的凭证不能转让。

**发起融资**：

1. 点击「发起融资」，选择融资金额（≤ 持有余额）。
2. 提交后**凭证自动托管进融资池**——同一份额不会同时出现在两个申请中（第二道防重复闸）。
3. 凭证在「我的融资管理」中显示为「开放中」。

### 4.4 处理报价

1. 「我的融资管理」→ 点击开放中的申请，查看各资金方报价。
2. 每条报价显示贴现率与**实际到手金额**（= 融资金额 × (1 − 贴现率)）。
3. 选择最优报价，点击「接受报价」：
   - 一笔交易内自动完成「凭证 → 资金方、贴现后资金 → 供应商」两步，任一步失败整笔回滚。
4. 不接受任何报价时可「取消申请」，凭证退回，可随时重新发起。

> 提示：资金方持有的凭证不能再转让，只能等待兑付——这是防止融资后重复转让的第三道闸。

## 五、核心企业操作指南

### 5.1 确认 / 拒绝发票

1. 仪表盘查看「待确认发票」数量与金额。
2. 进入「待确认发票」，点击「预览」在线查看 PDF，并核对：
   - 文件哈希与链上哈希是否一致（页面自动校验）；
   - 金额、到期日与内部 ERP 应付记录是否一致。
3. **确认**：点击「确认发票（上链）」。确认成功后系统自动铸造等额 ERC-1155 应收凭证给供应商。
   - 只能确认开给本企业的发票，合约会校验。
4. **拒绝**：必须填写拒绝原因。拒绝后释放去重键，供应商修改后可重新提交。

### 5.2 到期付款

1. 「应付账款清册」按到期日排序展示所有应付凭证（含已融资给资金方的）。
2. 到期前页面显示「临期预警」。
3. 点击「立即付款」：
   - 若 mUSD 授权额度不足，页面先引导执行 `approve` 授权；
   - 授权后执行 `repay`，将面值全额付入融资池。
4. 付款成功后，凭证持有人即可兑付。
5. **逾期未付**：资金方会标记逾期，逾期记录全网仪表盘可见，影响企业信用。

> 逾期后仍然可以付款，付款后凭证状态由「逾期」转为「已还款」。

## 六、资金方操作指南

### 6.1 在融资市场报价

1. 「融资市场」查看所有开放中的融资申请（供应商、金额、到期日）。
2. 点击「报价」，输入**贴现率**（单位 bps，300 = 3.00%）。
3. 页面实时预览：供应商到手金额、你的预期收益。
4. 提交报价前需先授权并锁定 mUSD 资金（页面引导两步操作）。
5. 多家资金方可对同一申请报价，供应商择优接受。
6. 报价未被接受前可随时「撤回报价」，锁定的资金原路取回。

### 6.2 管理放款资产

「我的放款资产」显示你持有的全部凭证（面值、到期日、状态）：

- **已成交**：凭证已划转到你的地址，等待核心企业到期付款。
- **兑付**：核心企业付款后，点击「兑付」——销毁凭证，按面值 1:1 领取 mUSD（一次兑付全部余额）。
- **标记逾期**：到期后核心企业仍未付款时，点击「标记逾期」。未到到期日不能标记。
- **逾期后**：可继续等待企业付款，付款后状态恢复，正常兑付。

### 6.3 领取测试币

页面提供「领取测试币（faucet）」入口，每次领取固定金额 mUSD，用于演示报价与付款。领取前确保钱包有足够 Sepolia ETH 支付 Gas。

## 七、审计员操作指南

### 7.1 全局审计看板

查看平台全貌：发票总数、凭证流转总额、逾期率、冻结凭证数，以及最新可疑事件（重复登记拦截、冻结、逾期标记）。

### 7.2 凭证穿透追踪

1. 输入凭证 ID，查看该凭证全生命周期流转树：
   铸造 → 拆分转让 → 融资申请 → 放款 → 还款 → 兑付，每一步附时间与交易哈希。
2. 发现可疑凭证时的处置：
   - **冻结**：填写原因（必填）后上链冻结。冻结后该凭证不可转让、融资、兑付。
   - **解冻**：核查无误后填写原因解冻。
3. 系统紧急暂停期间，冻结与解冻仍然可以执行，便于应急处置；所有操作链上留痕。

## 八、管理员操作指南

### 8.1 资质审核

1. 「资质审核管理」查看待审核企业（名称、地址、申请角色、提交时间）。
2. **通过**：点击「通过（链上授权）」→ MetaMask 签名执行 `grantRole` → 申请人刷新后进入对应工作台。授权交易哈希自动回写记录。
3. **驳回**：必须填写驳回原因，记录留档。
4. 一个地址同一时间只能持有一种角色。

### 8.2 角色与系统控制

- **撤销角色**：对违规地址执行 `revokeRole`，撤销后其所有写操作被合约拒绝。
- **紧急暂停**：出现系统性风险时点击「一键暂停」。暂停期间所有业务写操作失败并提示「系统已暂停」，查询不受影响；**例外**：管理员的角色授予/撤销、审计员的冻结/解冻仍可执行。
- **恢复**：风险排除后点击「恢复系统」，全功能恢复。

## 九、常见问题与故障排查

| 现象 | 原因 | 解决办法 |
| :--- | :--- | :--- |
| 提示「发票已存在」 | 同发票号+买卖双方+金额组合已登记 | 核对是否重复提交；如原发票被拒绝，确认去重键已释放后重新提交 |
| 提示「系统已暂停」 | 管理员执行了紧急暂停 | 联系管理员；暂停期间查询功能正常 |
| 提示「当前账户没有执行该操作的权限」 | 地址角色不符或角色已被撤销 | 确认登录地址正确；联系管理员核查角色状态 |
| 提示「凭证已被冻结」 | 审计员冻结了该凭证 | 联系审计员核查后解冻 |
| 提示「接收方不是已注册的供应商」 | 拆分转让目标地址未注册 | 请接收方先完成注册并通过审核 |
| 提示「mUSD 余额或授权额度不足」 | ERC-20 余额/approve 额度不够 | 先领取 faucet 测试币；按页面引导完成 approve |
| 提示「还没到期，不能标记逾期」 | 到期日未到 | 到期日之后且未付款时才能标记 |
| 交易一直 pending | Sepolia 网络拥堵或 Gas 过低 | 在 MetaMask 中加速（提高 Gas）或等待；不要重复提交 |
| 切换账户后页面没变化 | 前端未检测到账户切换 | 刷新页面；确认 MetaMask 已解锁 |
| 发票详情哈希校验不一致 | PDF 文件被改动 | 文件内容任何变化都会改变哈希；请使用原始 PDF |

> 完整错误码对照见 [`contracts/docs/interface.md` 错误表](../../contracts/docs/interface.md)。

## 十、术语表

| 术语 | 说明 |
| :--- | :--- |
| 应收账款 | 核心企业确认应付给供应商的货款债权 |
| 应收凭证（Receivable） | 发票确认后铸造的 ERC-1155 数字凭证，可拆分、转让、融资 |
| 拆分转让 | 将凭证按份额部分转让给另一供应商 |
| 贴现率（bps） | 万分之一单位，300 = 3.00%；到手金额 = 金额 × (1 − 贴现率) |
| 原子化放款 | 接受报价的一笔交易内同时完成「凭证划转 + 资金转账」，失败整笔回滚 |
| 兑付（redeem） | 核心企业付款后，凭证持有人销毁凭证按 1:1 领取 mUSD |
| 去重键 | 发票号+买方+卖方+金额的组合哈希，链上查重的依据 |
| mUSD | MockStablecoin，模拟 USDT 的测试稳定币（6 位小数） |
| Sepolia | 以太坊测试网，本项目部署环境 |
| Gas | 链上交易手续费，用 Sepolia ETH 支付 |
