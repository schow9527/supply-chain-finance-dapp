# 前端模块 (Frontend DApp UI)

> **责任人**：成员 3  
> **技术栈**：HTML5, CSS3, JavaScript (ES6+), Ethers.js (v6 或 v5), MetaMask Extension  

---

## 目录结构

```
frontend/
├── static/
│   ├── css/               # 样式表 (响应式布局、卡片、表格、表单)
│   │   └── style.css
│   ├── js/                # 前端交互与 Web3 逻辑
│   │   ├── web3-provider.js # MetaMask 连接、切链监听、合约封装
│   │   └── abi/           # 智能合约 ABI JSON 存放目录
│   └── images/            # 静态图标与 UI 素材
├── templates/             # 页面模板 (共 19 个页面/视图)
│   ├── base.html          # 公共导航栏、钱包状态条、Footer
│   ├── index.html         # 首页与钱包连接入口
│   ├── register.html      # 企业注册入驻页
│   ├── supplier/          # 供应商视图 (发票上传、凭证列表、融资申请)
│   ├── core_enterprise/   # 核心企业视图 (待确认发票、应付账款清册)
│   ├── financier/         # 资金方视图 (融资市场、报价放款、资产管理)
│   ├── auditor/           # 审计员视图 (全局看板、凭证追踪、冻结操作)
│   └── admin/             # 管理员视图 (资质审核、角色管理、紧急暂停)
└── README.md
```

## 核心职责
1. **钱包连接与网络守卫**：检测 MetaMask，提示切换至 Sepolia 测试网，监听账户切换并自动刷新角色视图。
2. **5 类角色路由与交互**：
   - 供应商、核心企业、资金方、审计员、管理员专属操作控制台。
3. **链上交易交互体验**：
   - 交易发起前预估 Gas（F-26）；
   - 展示 4 态流程：预估费用 -> 钱包签名 -> 链上确认中 -> 交易成功/失败；
   - 包含友好中文/英文错误原因解析（如拦截重复发票、未授权、被冻结等）。
4. **响应式设计**：适配 PC 与移动端浏览器。
